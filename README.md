# 🤖 AI Chatbot

An AI-powered chatbot web application that provides interactive conversations using the Google Gemini API. The application uses a modern frontend with a Node.js and Express.js backend to securely handle AI API requests.

## ✨ Features

- 🤖 AI-powered conversations
- 💬 Real-time chat interface
- 🔐 Secure API key handling using environment variables
- ⚡ Node.js and Express.js backend
- 🎨 Modern and user-friendly interface
- 🧹 Clear conversation functionality
- 📱 Mobile-responsive design

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Venkateshnarr/AI--Chatbot.git
```

### 2. Navigate to the Project Directory

```bash
cd AI--Chatbot
```

### 3. Install Dependencies

```bash
npm install
```

## 🔑 Gemini API Configuration

This project uses the Google Gemini API to generate AI-powered responses.

### Create a `.env` File

Create a `.env` file in the root directory of the project and add:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Replace `your_gemini_api_key_here` with your actual Gemini API key.

> ⚠️ Never upload your actual API key to GitHub. Make sure `.env` is included in your `.gitignore` file.

## ▶️ How to Run

Start the Node.js server using:

```bash
node server.js
```

After the server starts, open the local URL shown in your terminal.

For example:

```text
http://localhost:3000
```
